# Timed Survival Prototype

EN:

This is the proof of concept for a 3D timed survival game developed entirely within Godot with GDScript. It features a procedurally generated environment that ensures a unique layout for every session and autonomous enemy entities implemented with NavMesh navigation and with state‑based logic. To create a dynamic gameplay loop, proximity‑driven triggers and timed activations were used to make the enemies hunt the player. For further immersion, spatial audio scaling based on player distance was introduced. Tech demos for this project can be found on the following links:

RO:

Acesta este un proof of concept pentru un joc de supraviețuire contra‑cronometru, dezvoltat integral în Godot folosind GDScript. Proiectul include un mediu generat procedural, asigurând un layout unic pentru fiecare sesiune, și entități inamice autonome implementate cu navigație de tip NavMesh și logică bazată pe stări. Pentru a crea un gameplay loop dinamic, am utilizat triggeri de proximitate și secvențe de activare temporizate pentru a declanșa urmărirea jucătorului. Pentru o imersiune sporită, am integrat un sistem de scalare audio spațială în funcție de distanța în timp real față de jucător.
