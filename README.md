# Timed Survival Prototype

EN:

This is the proof of concept for a 3D timed survival game developed entirely within Godot with GDScript. It features a procedurally generated environment that ensures a unique layout for every session and autonomous enemy entities implemented with NavMesh navigation and with state‑based logic. To create a dynamic gameplay loop, proximity‑driven triggers and timed activations were used to make the enemies hunt the player. For further immersion, spatial audio scaling based on player distance was introduced. Tech demos for this project can be found on the following links:
